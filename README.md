# Ajob Data — Premium Electric Products

Full-stack Node/Express + Turso store. The UI follows the supplied Ajob Data black/red/gold reference direction and uses the supplied mascot logo. Demo products match the reference list.

## Render
- Root Directory: blank
- Build Command: `npm install`
- Start Command: `npm start`

## Environment variables
- `TURSO_DATABASE_URL`
- `TURSO_AUTH_TOKEN`
- `ADMIN_PASSWORD`

Admin panel: `/admin/`
